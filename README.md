# Тренажёры станций аккредитации

Интерактивные тренажёры для подготовки ко **второму этапу аккредитации** специалистов здравоохранения.

Проект помогает отработать практические станции и научиться правильно заполнять заключение — в своём темпе, с разбором и подсказками. Сделано студентом для студентов.

## 🔗 Открыть тренажёр

👉 **[Запустить](https://budekhins.github.io/akkreda/)**

## Что внутри

**Станция «Физикальное обследование пациента (сердечно-сосудистая система)»**

- Заполнение формы заключения по всем 10 сценариям паспорта станции.
- Мгновенная проверка: верные ответы подсвечиваются зелёным, лишние и пропущенные — отдельно.
- Разбор логики диагноза после каждой попытки.

### Режимы

- **📘 Обучение** — форма сразу заполнена эталонно, у каждого поля подсказка «почему так и как запомнить», сверху общий разбор сценария.
- **🎓 Зачёт** — случайный сценарий с закрытым диагнозом: определяешь сам по данным осмотра, ответ раскрывается после проверки.
- **🩺 Шпаргалка АД → диагноз** — группировка по диастолическому давлению для быстрого запоминания.

## Как пользоваться

Просто открой ссылку в браузере — ничего устанавливать не нужно. Работает на компьютере и телефоне.

## Источник данных

Сценарии и форма заключения соответствуют паспорту экзаменационной станции «Физикальное обследование пациента (сердечно-сосудистая система)», Методический центр аккредитации специалистов, 2023 г.

## Важно

Это **неофициальный учебный тренажёр** для самоподготовки. Он не заменяет официальные методические материалы и не является источником клинических рекомендаций. Перед экзаменом сверяйтесь с актуальной версией паспорта станции.
